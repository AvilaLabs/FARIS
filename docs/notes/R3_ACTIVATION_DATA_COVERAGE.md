# R3 activation data gate: not evaluated

Recorded 2026-11-09. This is a read-only preflight of the prospective full-emission
R3 D1S/R2S reference inputs; no R3 transport or activation solver was started.

## Finding

The OpenMC 0.15.3 p32 depletion chain (`d3b829467cfdda9c624aaeb5709825df378b908ecc63c3f984ade51f8d0444a0`)
has 3,820 nuclides. Following listed reaction and decay targets from the 22 RM-M
material nuclides reaches 2,582 nuclides, 2,188 of which have neutron reactions
in the chain. The current combined FARIS `cross_sections.xml`
(`fd9d79db8c8569f0f88ff56f37314c27d56562e70a4645280d1a8355575f0b9b`) has
entries for the 22 material roots, but only 20 of the 2,188 reachable
reaction-bearing nuclides. It also lacks 12 chain-listed reaction MT groups
among the indexed root nuclides, including `(n,3n)` (MT 17) for Be9, Cu63/65,
F19, Fe54/56/57 and Ti46–49, plus `(n,4n)` (MT 37) for Fe57. The complete
missing-nuclide list and the missing-channel list are generated by
`r3_activation_coverage.assess_coverage` from the exact files.

As context, the standalone FENDL-3.2 partial index covers 13/2,188 reachable
reaction nuclides and omits 15 RM-M roots. Local ENDF/B-VIII.1 covers 537/2,188
and omits 1,651 reachable reaction nuclides. Those counts are index/channel
presence only, not quality assessments.

The R3 runner previously asked OpenMC MicroXS for only the initial 22 material
nuclides. OpenMC 0.15.3 fills missing nuclide cross sections with zero and its
independent depletion operator treats chain nuclides without MicroXS as
decay-only. That would omit neutron transmutation of nearly all generated
activation products. The prospective OpenMC R2S reference therefore remains
**NOT_EVALUATED** with the installed data. The runner now requests every
reachable reaction-bearing nuclide plus all material roots, and stops before
R2S neutron transport unless both each nuclide and each chain-listed MT channel
are present. The exporter independently recomputes this check from the hashed
material XML, chain XML, cross-section index and indexed HDF5 files, then checks
the actual MicroXS HDF5 nuclide lists and their file hash. Old in-band D1S/R2S
records without this evidence are rejected.

ACTINV's available TENDL-2025 709-group library is a different activation
backend and data format. It may be useful as a separately labeled data-method
sensitivity, but substituting it would change the nuclear-data basis alongside
the method and does not qualify the frozen matched-data VAL-043 D1S/R2S
comparison.

Even a future `READY_FOR_R2S_TRANSPORT` result only establishes presence of all
chain-reachable nuclides and chain-listed MT groups in the indexed OpenMC data.
It does not qualify evaluation provenance or quality, reaction completeness
beyond the chain, decay data, branching adequacy, covariance, spectrum
collapse, composition, activation mesh convergence, or dose accuracy.
