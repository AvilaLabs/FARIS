# Requirements scorecard

Generated by `scripts/requirement_scorecard.py`; do not edit by hand.

Counts come from the requirement tables in this directory. The Now column is recorded by hand (see the [index](README.md) for its date) and a requirement counts as Met only when its own Now column says so. Traced means at least one test declares `Verifies:` for the requirement ([TRACE.md](TRACE.md)); it says a test exists, not that the target is met, and CI decides whether that test passes. Basis columns count requirements that carry the mark; a requirement can carry more than one, so they need not add up to the total. Struck-through (withdrawn) requirements are excluded.
