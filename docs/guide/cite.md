# How to cite FARIS

If you use FARIS in published work, cite the version you ran. The repository holds the same information in
machine-readable form in `CITATION.cff` (Citation File Format 1.2.0), which GitHub shows as **Cite this
repository**.

> Avila, Connor. FARIS, version 0.2.0 (2026-10-08). Avila Labs. https://github.com/AvilaLabs/FARIS. Licence: AGPL-3.0-only.

- **Software version.** The version is in the app's About box and in `faris --version`. Cite the one you used.
- **DOI.** None has been issued yet. When a release is archived with a DOI, `CITATION.cff` and this page gain it.
  Until then, cite the version and the repository address above.
- **Authors.** Connor Avila, Avila Labs.
- **Licence.** AGPL-3.0-only.

FARIS results are research screening only. A citation says which software produced a number; it does not make the
number a licensing, safety or design basis.
